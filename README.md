# madebymykids.com

Static site for **Made By My Kids** — games built from stories written by kids.
Plain HTML/CSS, no build step. Hosted on GitHub Pages (`CNAME` → madebymykids.com).

- `index.html` — home
- `battle-for-the-grail/` — game page
- `privacy.html` — privacy policy (linked from the Google Play / App Store listings)
- `img/grail/` — screenshots and art from the game repo (`tools/shots`, `store/`)

Preview locally: `python3 -m http.server 8765` then open http://localhost:8765/
